# ADR 0026 — 파이썬 판은 한 파일이 들고, 최신 안정판을 쓴다

- 상태: 채택
- 날짜: 2026-10-21
- 정한 사람: 저장소 소유자 — 「CI 와 작업 컨테이너의 판을 최신으로 맞춘다」(2026-10-21). 판과 방식은 추천으로 정했다(`Profile.md` 「업무에 영향이 없는 기술 결정」)

## 맥락

파이썬 판이 세 자리에 따로 있었다 — CI(`ci.yml` 의 `setup-python`) · 이미지(`Dockerfile` 의 `FROM`)는 3.12, 클라우드
세션의 `.venv` 는 훅이 그 컨테이너의 `python3` 로 지어 3.13 이었다. 조각 「이동」을 닫으며 같은 커밋을 돌렸더니 3.12 에서는
전체가 초록, 3.13 에서는 계약의 사진 대조(`test_the_spec_matches_the_snapshot_in_the_repository`) 하나가 빨갰다(감사 ㊺).

뿌리는 판이 아니라 **사진이 판에 기댄 것**이다. 쓰기 · 읽기 라우트의 오류 응답 선언에 설명 글자가 없어, FastAPI 가 그 자리를
표준 라이브러리의 상태 이름표(`http.client.responses`)로 채운다. 3.13 이 422 의 이름을 「Unprocessable Entity」에서 RFC 9110 의
「Unprocessable Content」로 바꿨다. 판만 올리면 빨간 쪽이 옮겨 갈 뿐이다 — 하한 3.11(`pyproject.toml`)로 도는 로컬이 빨개진다.

3.14 에서 확인한 것: 잠금 그대로 해시까지 설치된다 · 3.14 의 pip-compile 로 잠금을 다시 만들어도 고르는 판이 같다(`scripts/lock.sh
--check`) · ruff · mypy 깨끗 · 시험은 위의 하나만 빨갛다. 3.15 는 베타다.

## 대안

- **가) 3.12 에 둔다** — 세션 훅만 3.12 로 짓게 한다. 바꾸는 것이 가장 적지만 판의 사본 셋은 그대로 남고, 사진은 여전히 판에 기댄다
- **나) 최신 안정판 3.14 로 올리고, 판을 한 파일이 든다** — 사진이 이름표에 기대지 않게 설명 글자를 코드가 든다
- **다) 3.15 베타** — 「최신」이지만 정식판이 아니고, 휠이 없는 의존성이 나올 수 있다

## 결정

**나).**

- 판은 `backend/.python-version` 한 자리다. CI 는 `python-version-file` 로, 세션 훅은 `cat` 으로 읽는다. 그 파일을 읽지 못하는 두
  자리 — 이미지의 `FROM` 과 잠금 머리의 「pip-compile with Python」 — 는 `tests/test_dependencies.py` 의
  `test_one_file_holds_the_python_version` 이 견준다
- 오류 응답(400 · 404 · 405 · 422 · 500)의 설명은 `app/api/app.py` 의 `_STATUS_TEXT` 가 든다 — RFC 9110 의 이름이다.
  `tests/test_api.py` 의 `test_the_spec_does_not_lean_on_the_python_status_names` 가 이름표를 비우고 다시 지어도 사진과 같은지 본다
- 하한 3.11 은 그대로다 — 「로컬이 3.11 이어도 같은 테스트가 돈다」가 이제 사진까지 참이다
- 세션 훅은 판이 다른 `.venv` 를 다시 짓고, 그 판이 컨테이너에 없으면 uv 로 받는다

## 결과

- 사진의 422 설명이 「Unprocessable Content」로 바뀐다. 계약 판정은 설명을 산문으로 보아 견주지 않으므로 판(`API_VERSION`)은
  그대로다
- 3.11 · 3.12 · 3.14 에서 같은 시험이 같은 결과다(이 결정을 낸 PR 이 셋 다 돌렸다)
- Dependabot 은 `pip` 만 본다(`.github/dependabot.yml`) — 판을 올리는 날은 사람이 `.python-version` 을 고치고, 이미지 · 잠금이
  따라오지 않으면 위 시험이 빨갛다
