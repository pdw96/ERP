# 런타임.
#
# **FastAPI** — 첫 쓰기 엔드포인트가 여기서 선다. 요청 본문을 파이썬 타입으로
# 검증하는 것을 이미 쓰는 pydantic 이 맡으므로 검증 규칙이 두 벌이 되지 않고,
# 타입힌트에서 OpenAPI 가 나와 「문서와 코드가 다르다」가 구조적으로 줄어든다.
#
# **uvicorn** — FastAPI 는 ASGI 앱일 뿐이라 띄우는 것이 따로 있어야 한다.
# 표준 ASGI 서버이고 compose 의 `api` 서비스가 이것으로 뜬다. 빈 의존성을 두지
# 않는다는 규칙대로, 부르는 쪽이 생기는 이 조각에서 함께 온다.
# **starlette 를 함께 고정한다.** FastAPI 는 그것을 `>=` 로만 묶으므로 고정하지
# 않으면 설치하는 날마다 다른 버전이 온다 — 실제로 CI 가 1.6.0 을 골라 테스트
# 클라이언트가 다른 패키지를 요구했고, 그 버전이 이미 깔려 있던 로컬만 통과했다.
# **환경에 따라 다르게 도는 검사**는 검사가 아니다.
